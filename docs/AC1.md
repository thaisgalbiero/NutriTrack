# AC1 — NutriTrack

## Objetivo
Implementar a primeira versão funcional do sistema, demonstrando a integração entre front-end, back-end e banco de dados.

## Funcionalidades entregues
1. Cadastro de usuário
2. Login
3. Logout
4. Cadastro de alimentos
5. Listagem de alimentos
6. Persistência no banco de dados
7. API REST
8. Front-end consumindo a API

## Fala sugerida
"Neste primeiro sprint desenvolvemos a base do NutriTrack. O objetivo foi construir a arquitetura inicial do sistema e demonstrar a comunicação entre front-end, back-end e banco de dados. Nesta versão o usuário consegue criar sua conta, realizar login e cadastrar alimentos, que são persistidos no banco através de uma API REST."
